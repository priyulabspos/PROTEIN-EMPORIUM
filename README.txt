PROTEIN EMPORIUM - WooCommerce theme

1. WordPress admin > Plugins > install and activate WooCommerce (+ Razorpay plugin for payments, YITH Wishlist optional).
2. Appearance > Themes > Add New > Upload Theme > protein-emporium.zip > Activate.
3. Settings > Reading > "Your homepage displays" = A static page. Create an empty page called Home and select it
   (front-page.php is used automatically).
4. WooCommerce > Products: create categories (Whey Protein, Creatine, Pre Workout, Aminos, L Carnitine, Gainers, Vitamins, Health Food)
   and add products with images. Products without an image show the built-in SVG pack.
5. WooCommerce > Settings > Products: enable AJAX add to cart on archives. Shipping: free above Rs 499. Payments: UPI/Razorpay, COD.
6. Coupons: create PROTEIN5 (5%) and FIRST10 (10%) under Marketing > Coupons.
